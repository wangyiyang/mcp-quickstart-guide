> 我们使用FastMCP（HTTP Transport）、pyecharts实现一个MCP Server, 大模型通过加工用户输入的信息，传入的图表类型调用我们不同的 MCP 工具来生成不同的图表，返回图表的URL。我们现在需要支持柱状图、饼图、折线图。我们的流程：

  1. 大模型调用MCP 某个图形生成工具，传入响应的参数
  2. Pyecharts 根据参数生成图表并渲染成html, 保存到临时文件夹
  3. 将html文件渲染或通过一些工具截图生成图片（请注意如果使用截图注意截图的尺寸， 不要截取的不完整也不能过度留白）
  4. 将生成的图片上传到MinIO并返回URL

  如果你不清楚 FastMCP、pyecharts 如何使用，请使用/context7 进行文档搜索

  另外：

  - 配置文件我们使用Dynaconf 进行管理
  - 日志我们使用loguru

     项目架构设计

     核心技术栈

     - FastMCP: HTTP Transport模式的MCP服务器框架
     - pyecharts: 图表生成库，支持柱状图、饼图、折线图
     - MinIO Python SDK: 对象存储服务，用于图片上传和URL返回
     - Dynaconf: 配置管理
     - loguru: 日志记录
     - Playwright/selenium: HTML转图片截图工具

     项目结构

     核心功能实现

     1. MCP工具定义

     创建三个主要MCP工具：
     - generate_bar_chart: 生成柱状图
     - generate_pie_chart: 生成饼图  
     - generate_line_chart: 生成折线图

     2. 图表生成流程

     1. 接收参数: 通过MCP工具接收图表数据和配置
     2. 创建图表: 使用pyecharts生成对应类型的图表
     3. 渲染HTML: 将图表渲染为临时HTML文件
     4. 截图转换: 使用Playwright将HTML转换为高质量图片
     5. 上传存储: 将图片上传到MinIO对象存储
     6. 返回URL: 返回图片的公网访问URL

     3. 技术实现要点

     FastMCP服务器配置

     - 使用HTTP Transport模式，默认监听127.0.0.1:8000
     - 支持跨域请求和错误处理
     - 集成loguru日志记录

     图表参数设计

     每个图表工具支持以下通用参数：
     - title: 图表标题
     - data: 图表数据（格式因图表类型而异）
     - width: 图表宽度（默认800px）
     - height: 图表高度（默认600px）
     - theme: 主题样式（默认'white'）

     截图优化

     - 设置合适的viewport尺寸
     - 等待图表完全渲染
     - 优化截图质量和文件大小
     - 自动裁剪多余的白边

     MinIO集成

     - 支持自定义bucket配置
     - 自动生成唯一文件名（UUID + 时间戳）
     - 返回带过期时间的预签名URL
     - 支持自定义域名配置

     4. 配置管理

     使用Dynaconf管理配置，支持：
     - MinIO服务器连接信息
     - 图表默认样式配置
     - 临时文件清理策略
     - 日志级别和输出配置

     5. 错误处理和日志

     - 完整的异常处理机制
     - 详细的操作日志记录
     - 临时文件自动清理
     - 优雅的错误信息返回

     部署和使用

     开发环境启动

     python main.py
     # 服务将在 http://127.0.0.1:8000/mcp 启动

     Claude Code集成

     用户可在Claude Code中配置MCP服务器，通过自然语言请求生成图表：
     "请生成一个销售数据的柱状图，包含Q1到Q4的季度数据"

     扩展性考虑

     - 模块化设计，易于添加新的图表类型
     - 支持多种截图引擎（Playwright/Selenium）
     - 配置化的存储后端（可扩展到AWS S3等）
     - 标准化的错误处理和日志格式

     这个实现方案遵循了DRY、KISS、SOLID和YAGNI原则，提供了完整的图表生成和存储解决方案。
